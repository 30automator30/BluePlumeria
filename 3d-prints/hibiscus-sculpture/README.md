# Hibiscus sculpture (draft, superseded)

A draft companion to the lattice plumeria, about 99 mm tall (1/φ of the plumeria's height):
- an open hibiscus with a filleted vein lattice in each petal and a staminal column;
- a rope-of-braids trunk.

This was a draft for approval. The design went on as **`../hibiscus-bonsai/`**, which was built, printed clean and documented, so start from that folder.

- **`hibiscus_sculpture.py`:** the draft generator. `--voxel 0.25 --preview` gives a quick look. It imports `lattice_plumeria` and `fractal_plumeria` from `../fractal-plumeria/`.
